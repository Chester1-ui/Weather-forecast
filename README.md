# 🌦️ Weather Dashboard

A Python-based weather dashboard that retrieves real-time weather information using the OpenWeather API and displays current conditions, a 5-day forecast, and temperature trends through interactive visualisations.

I built this project to improve my understanding of Python development, REST APIs, JSON data handling, and data visualisation.

---

## 🚀 Features

### Current Weather
- Search for weather information by city
- Displays:
  - Temperature
  - Feels-like temperature
  - Humidity
  - Wind speed
  - Weather conditions
  - Weather icons

### 5-Day Forecast
- Retrieves future weather predictions
- Displays a daily forecast layout
- Shows:
  - Date
  - Weather condition
  - Temperature
  - Weather icons

### Data Visualisation
- Interactive temperature forecast graph
- Built using Plotly

### Error Handling
- Handles invalid city searches
- Provides user feedback when API requests fail
